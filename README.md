# BusTime 🚌

Projeto web da disciplina **WEB 1**: protótipo de um site de transporte público com cadastro, login e página principal com horários, rotas, motoristas e veículos.

## Páginas

| Arquivo | Tela |
|---|---|
| `html/login.html` | Login |
| `html/criar-conta.html` | Cadastro de usuário |
| `html/principal.html` | Página principal |

## Tecnologias

HTML · CSS · JavaScript

## Como rodar

Abra `html/login.html` no navegador. O cadastro e o login são simulados na página (sem servidor ou banco de dados).
